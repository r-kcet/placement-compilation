# KCET Engineering College Placement Compilation

A community-compiled placement report for KCET engineering colleges, put together by the
[r/kcet](https://www.reddit.com/r/kcet/) community.

> **Disclaimer:** This is an unofficial, community-maintained archive. Data is shared as-is and may
> be incomplete, outdated, or inaccurate. Always cross-check with the official college placement
> cell before making decisions.

## Contributing

**Anyone can contribute.** You do not need to be a mod or a student of a particular college. If you have placement data that is publicly available, you can add it.

### How to Contribute

1. Fork this repository.
2. Add your files inside the folder for the relevant college (create the folder if it does not exist).
   Name files clearly, including the college and the batch/year where possible.
3. Commit your changes using the format below.
4. Open a pull request describing what you added.

### Commit Message Format

Every contribution commit must include a **source**. **Credit is optional** include it if you
want to be acknowledged, or leave it out if you prefer privacy.

```
<college> <batch/year> credit:<alias or name>

Source:<link to the original post, sheet, or official page>
```

Example:

```
rvce 2027 credit:u/Limp_Industry7281

Source:https://www.reddit.com/r/Btechtards/comments/1xgpz65/rvce_placements_2027/
```

- **Source is mandatory.** Every commit must link to where the data came from (a Reddit post, an
  official college page, a shared sheet, etc.). Contributions without a source will not be merged.
